# voxup's models (2026-11-21). Each block: one model in the window's list.
#   model ID          the name of its graph (ID.json beside this file) and of its pictures (ID-sSEED.png)
#   name TEXT         shown in the list
#   note TEXT         shown when the mouse is over it
#   prompt draw|edit  the standard prompt: "draw" (describe and draw anew; Klein's) or "edit" (an instruction; Kontext's)
#   file FOLDER NAME BYTES URL   a file it needs, in ComfyUI-Shared\models\FOLDER; got from URL when missing
#   prompt tags       Stable Diffusion's kind of prompt (short phrases)
#   sd ctx KEY VALUE  the built-in engine (stable-diffusion.cpp): a loading option; "files:FOLDER/NAME" = that file
#   sd img KEY VALUE  the built-in engine: an option for every picture (keys: stable-diffusion.cpp docs/guides/c_api.md)
#   sd image ref|init the item's picture as a reference picture (ref, edit models) or as the start picture (init)
#   sd strength N     init: how much may change, %, the window's standard (ComfyUI graphs: "@STRENGTH@")
#   sd lora FOLDER NAME N   a LoRA at N %, the window's standard (ComfyUI graphs: "@LORA@")
# A model with sd lines can be drawn inside voxup (Engine: Built-in); with a graph, by ComfyUI; with both, by either.
# The graphs are ComfyUI API graphs taken from ComfyUI's own templates (comfyui_workflow_templates_json 0.1.74, ComfyUI
# 0.35.1); in them "@IMAGE@", "@PROMPT@", "@SEED@" and "@PREFIX@" are filled in for every picture.
# Left out on purpose: FLUX.2 Klein 9B base/distilled (Hugging Face login needed), FireRed 1.1 (41 GB), FLUX.2 dev
# (71 GB), Chrono/Capybara (video models).
